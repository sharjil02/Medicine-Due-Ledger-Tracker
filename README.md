# Medicine Due & Monthly Ledger Tracker

A comprehensive, responsive web application for pharmacies and medicine stores to track customer medicine dues, monthly ledgers, payment transactions, customer records, and analytics.



Live Link - https://sharjil02.github.io/Medicine-Due-Ledger-Tracker/

---

## 🌟 Key Features

- **📊 Dashboard & Metrics Overview**: Real-time stats on total dues, collections, monthly summaries, active customers, and overdue alerts.
- **👥 Customer Management**: Add, update, view customer profiles with complete contact details and individual transaction ledgers.
- **💊 Due & Ledger Tracking**: Record sales on credit, partial/full payments, and automatically update running balances.
- **📅 Monthly Statements**: Filter and generate monthly financial summaries, monthly dues, and collection histories.
- **🔍 Search & Filter**: Instant search across customer names, phone numbers, invoice/receipt IDs, and date ranges.
- **📱 Responsive Design**: Optimized for desktops, tablets, and mobile devices.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v14 or higher recommended)

### Installation & Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sharjil02/Medicine-Due-Ledger-Tracker.git
   cd Medicine-Due-Ledger-Tracker
   ```

2. **Start the local server:**
   ```bash
   npm start
   ```
   *Alternatively:*
   ```bash
   node server.js
   ```

3. **Open in your browser:**
   Visit [http://localhost:3000](http://localhost:3000)
